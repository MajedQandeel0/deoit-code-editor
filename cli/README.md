# Deoit CLI

Open **[Deoit](https://deoit.js.org)** — the browser-based IDE for HTML, CSS & JavaScript — right from your terminal.

No local setup. No toolchain. Just open and build.

## Install

```bash
npm install -g deoit-cli
```

## Usage

```bash
deoit                  # Open Deoit in your browser
deoit open             # Open Deoit in your browser
deoit new <name>       # Create a new project folder and open Deoit
deoit embed            # Copy embed code to clipboard
deoit --help           # Show this help message
deoit --version        # Show version number
```

## Examples

```bash
deoit                  # Opens deoit.js.org
deoit new my-app       # Creates ./my-app and opens Deoit
deoit embed            # Prints <iframe> embed code
```

## What is Deoit?

Deoit is a browser-based IDE with:

- Advanced code editor — syntax highlighting, autocomplete, 7 themes
- File explorer with multi-file project support
- Live preview in a sandboxed popup
- Built-in console
- 81+ reference lessons for HTML, CSS, JavaScript, React, Node.js & DevTools
